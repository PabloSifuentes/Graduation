TECNOLOGIAS DO PROJETO

Este projeto utiliza exclusivamente:

HTML5
CSS3
JavaScript Vanilla
Diretrizes técnicas
Não utilizar React, Vue, Angular ou Next.js.
Não introduzir frameworks CSS sem autorização.
Priorizar JavaScript puro.
Respeitar a estrutura atual dos arquivos.
Separar adequadamente estrutura, estilos e comportamentos.
Evitar CSS duplicado.
Evitar JavaScript desnecessariamente complexo.
Utilizar recursos modernos e compatíveis com navegadores atuais.
Garantir responsividade sem comprometer o desktop.
Preservar a identidade visual existente.
Análise específica do formulário

Verificar:

Campos obrigatórios.
Máscaras de entrada, quando aplicáveis.
Validação de e-mail.
Validação de senhas.
Confirmação de senha.
Feedback visual de erros.
Mensagens de sucesso.
Estados de carregamento.
Prevenção de múltiplos envios.
Navegação por teclado.
Acessibilidade dos campos.

Não simular persistência de dados no backend. O projeto possui somente frontend nesta etapa.
