Instalação

Passos para rodar o projeto localmente

1
Clone o repositório
git clone https://github.com/seu-usuario/specai-api.git
2
Entre na pasta
cd specai-api
3
Configure o banco
spring.datasource.url=jdbc:mysql://localhost:3306/specai
spring.datasource.username=root
spring.datasource.password=123456
spring.jpa.hibernate.ddl-auto=update
4
Execute
./mvnw spring-boot:run
